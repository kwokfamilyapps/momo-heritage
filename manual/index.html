影相

  1. 喺填寫頁㩒「📸 拍攝相片」區域
  2. 揀「相機」即時影相，或「相片庫」選已有相片

相片儲存方式

相片會儲存喺兩個地方：

  • 📱 手機瀏覽器 IndexedDB — 永久儲存，熄 App 再開都喺度
  • 📤 分享/下載 — 影相後會自動彈出分享選單（iOS）或下載（Android/桌面）

iPhone 儲存步驟

  1. 影相後會彈出 iOS 分享選單
  2. 你可以揀：
    • 「儲存到照片」 — 直接存入相機膠卷
    • 「儲存到檔案」 — 可以揀 iCloud / 手機資料夾，自行建立「山徑巡查」folder
    • AirDrop — 傳去其他裝置
  3. 檔案名格式：山徑巡查_2026-07-22_10-30-00.jpg
⚠️ iOS 限制：iPhone Safari 唔支援自動儲存到特定 folder。每次都要手動揀「儲存到照片」或「儲存到檔案」。建議用「儲存到照片」，之後開 Photos app 就會見到。

🗺️ 地圖 — 重組山徑路線

呢個係 App 嘅核心功能！每次提交記錄時系統會自動記錄 GPS 位置，所有 GPS 點會連接成你嘅巡查路線。

點解地圖冇顯示？

  1. 檢查提交時 GPS 有冇開啟（手機頂部下拉 check 位置權限）
  2. 第一次用時瀏覽器會問「允許取用位置？」— 要㩒「允許」
  3. 喺室內或密林 GPS 信號弱，可以試出去空曠地方
  4. 提交後等約 10 秒（GPS 背景 capture）

地圖元素解說

地圖元素意思
🟢 綠色圓點山徑問題記錄點
🔵 藍色圓點水道記錄點
- - - 綠色虛線山徑巡查路線（連接各山徑記錄點）
- - - 藍色虛線水道巡查路線（連接各水道記錄點）

地圖互動

  • 㩒 GPS 點 — 彈出 Popup 顯示該記錄嘅詳情（山徑名、日期、問題、相片數）
  • 兩指撥動 — 放大縮小
  • 拖曳 — 移動地圖
  • 路線虛線 — 綠色 = 山徑路線，藍色 = 水道路線，按記錄時間順序連接

路線重組原理

  1. 每次提交記錄，系統 capture 你嗰一刻嘅 GPS 座標
  2. 山徑記錄點用綠色虛線連接，水道記錄點用藍色虛線連接
  3. 地圖上可以同時顯示兩條路線，唔會撈亂
  4. 記錄越多，路線越完整
💡 季節對比：夏天同冬天行同一條路線，可以對比唔同季節嘅問題變化。Admin 可以匯出 CSV 分析趨勢。

☁️ 資料同步

雲端儲存（Firebase Firestore）

  • 所有記錄（文字資料）會自動 sync 上 Firebase 雲端
  • 義工同 Admin 用同一個資料庫，睇到嘅記錄係一樣
  • 離線時記錄會暫存手機，有網絡時自動 sync

sync 失敗處理

如果 sync 失敗（例如網絡問題），App 會彈 Alert 話你知 error 原因。記錄仍然保留喺手機本地，唔會流失。

咩嘢唔會上雲端？

  • 相片 — 只存手機本地（IndexedDB），唔上雲端
  • GPS 座標 — 會上雲端（記錄入面有 gps 字段）

🚪 退出 App

  1. 㩒底部導航欄「🚪 退出」
  2. 確認後會登出，返回登入頁
  3. 要再使用時㩒「義工隊登入」或「Admin 登入」
💡 就算唔㩒退出，直接熄 browser tab 都得，資料已經 sync 咗。

📡 離線操作（冇信號區域）

鞍山山徑好多地方收唔到信號，App 設計咗離線功能，你可以照常操作。

離線前準備

  1. 出發前喺有信號嘅地方 開一次 App 並登入
  2. App 會自動 cache 必要嘅資料
  3. 唔好關閉個 browser tab（可以熄 mon，但唔好 swipe 走個 tab）

離線時做到嘅事

功能離線備註
📝 記錄問題✅暫存手機，有信號時自動 sync
📸 影相✅存 IndexedDB + 分享選單
📍 GPS 記錄✅手機 GPS 唔使網絡
📋 睇已有記錄✅之前 load 過嘅記錄睇到
🗺️ 地圖❌地圖 tiles 需要網絡
Admin 統計❌需要 Firestore 連線

離線操作步驟

  1. 照常打開 App（如果之前開過，唔使重新整理）
  2. 㩒「義工隊登入」
  3. 填寫記錄、影相、提交 — 全部正常操作
  4. 記錄會暫存喺手機本地

返到有信號後

  1. App 會 自動 sync 離線期間嘅記錄上雲端
  2. 唔使㩒任何掣，Firestore SDK 背景自動處理
  3. 如果 sync 失敗會彈 Alert 通知你
💡 貼士：
  • 離線時記錄 sync 唔到上雲端，但唔會流失
  • 返到市區開 App，等幾秒就會自動 sync
  • 建議每日完成巡查後，喺有信號嘅地方開一開 App 確認 sync 成功
  • 地圖離線用唔到，但 GPS 仍然會記錄位置，有信號後地圖就會顯示返
⚠️ 重要：如果喺離線時 swipe 關閉 browser tab 或重新整理頁面，未 sync 嘅記錄仍然喺 IndexedDB 入面，唔會流失。但重新開 App 時需要網絡連線先 load 到最新資料。

❓ 常見問題

Q: 記錄提交後去咗邊？

A: 即時 sync 上 Firebase 雲端。你熄 App 再開，資料仍然喺度。

Q: 點解地圖冇顯示我嘅 GPS 點？

A: 可能原因：① 提交時 GPS 未開啟 ② 位置權限未允許 ③ 喺室內或密林 GPS 信號弱。可以去查閱頁睇記錄有冇自動 capture 到位置。

Q: 義工同 Admin 有咩分別？

A: 義工可以記錄問題、編輯自己嘅記錄。Admin 可以睇所有記錄、匯出報表、編輯/刪除任何記錄、清除全部記錄。

Q: 可唔可以離線使用？

A: 可以。Firestore 有離線快取功能，冇網絡時記錄會暫存手機，有網絡時自動 sync。

Q: 點解影相咁慢？

A: App 會自動壓縮相片到 1024px（約 200-300KB），但如果用手機網絡下載，速度取決於你嘅連線。

Q: 相片會唔會 sync 上雲端？

A: 唔會。相片只儲存喺手機本地（IndexedDB）同自動下載到 Download 資料夾。

Q: 點解 Submit 時彈 Alert 話 sync 失敗？

A: 可能係網絡問題。記錄仍然留喺手機本地，唔會流失。等網絡穩定後再試就得。

Q: 點解登入 Admin 時話密碼錯誤？

A: 預設 Admin 密碼係 admin2024。如果想改密碼，通知 mvmv 幫手。

Q: 點解㩒「清除所有記錄」都刪唔到？

A: 需要兩次確認先會執行，防止誤刪。如果真係想清除，㩒兩次確認就得。

Q: 點樣匯出報表？

A: Admin 登入後，㩒「📋 查閱」頁，底部有「📊 匯出報表 (CSV)」掣。㩒之後會下載 CSV 檔，可以用 Excel 打開。

Q: 我可唔可以改密碼？

A: Admin 密碼目前係固定嘅 admin2024。如果想改，話俾 mvmv 知，可以幫手改。
